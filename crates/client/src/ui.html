glidekm can't create its virtual mouse and keyboard. Allow it once (needs your password; set one with passwd in Konsole if you haven't): 
echo 'KERNEL=="uinput", SUBSYSTEM=="misc", TAG+="uaccess", OPTIONS+="static_node=uinput"' | sudo tee /etc/udev/rules.d/60-glidekm-uinput.rules && sudo udevadm control --reload-rules && sudo udevadm trigger --name-match=uinput
Paste it into Konsole. glidekm retries automatically.
